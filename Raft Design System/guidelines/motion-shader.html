Data-attribute API (dither-banner.js)

data-dither / data-dither-banner — either selector self-mounts a shader; use whichever reads better at the call site.
data-shape — wave · sphere · simplex · dots · warp · ripple · swirl
data-type — random · 2x2 · 4x4 · 8x8 (Bayer dither matrix)
data-size / data-scale / data-speed / data-frame — pixel size, zoom, animation speed, start frame
data-light-front — a CSS variable name (e.g. --text-accent) to draw with in light mode instead of the default --bg-brand; updates live on theme toggle
data-messages — a JSON array; a sibling element with the exact class .raft-message-text (hardcoded in the script, not itself configurable) has its text rotated through the array, timed to swap while the shader's centre band is dark so the change is hidden by the dither itself

Pauses off-screen or when the tab is hidden; renders one still frame under prefers-reduced-motion. ~29KB, self-hosted (no CDN) — see the source comment in assets/dither-banner.js for the full mount/uniform reference.
